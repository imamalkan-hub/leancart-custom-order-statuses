Add your own statuses to your orders and manage your workflow.

**Example site:** https://qsedationdentistry.com
**Category:** Orders · **License price:** $19 (Business Bundle: $149)

## Features
* Unlimited custom statuses
* Bulk action support
* Compatible with the WooCommerce standard status list

## Installation
1. Download the ZIP from `build/zips/` or download this repository as a ZIP.
2. In WordPress Admin, go to Plugins → Add New → Upload Plugin.
3. Activate the plugin and configure it at **Settings → LeanCart Custom Order Statuses**.

## Requirements
- WordPress 6.2+, PHP 8.0+
- WooCommerce 8+ (HPOS compatible)
